# 新石器村落：文物依据与组合

资料与历史组合记录：下文保留v0.2的首次核对范围及待补证项，不将五区域、八对象视为当前数量。v0.10.1的村落为六区域、十个观察入口；后续空间依据见[场景建筑与地形规范](场景建筑与地形规范.md)，当前验证范围见[验证状态](验证状态.md)。

核对日期：2026-09-28。状态：首轮资料已用于 v0.2 的五个区域与八张对象卡。建筑、窑址与器形仍为风格化示意，待补证项见文末。

## 1. 选题结论

沿用现有裴李岗文化背景，将“一粟之间”扩展为一个小聚居村落的生活片段。主题问题调整为：**一份食物，怎样经过土地、工具、火与容器，进入史前人们的生活？**

以新郑裴李岗遗址资料为主体，少量引入同文化其他遗址的器物作比较参考。名称建议为“裴李岗生活村落 · 艺术重构”。这是一组有资料依据的生活情境，不是某一发掘区、某一年或某个家庭的精确复原。

文化背景可使用“距今约九千至七千年的裴李岗文化”，这一范围不代表所选器物全部同时使用。文化年代参考考古学者袁广阔的综述 [S7]；不把不同来源的概略年代强行换算为一个准确年份。

## 2. 聚落依据与适用范围

河南省文物考古研究院 2026 年的讲座实录介绍了裴李岗遗址生活区中的多组生产生活单元，包含房址、灰坑和陶窑，并提及木骨泥墙建筑；植物遗存包含栽培作物和野生果实 [S1]。这支持“住处与生产活动相联系”的场景组织，也提醒我们不要将食物来源画成只有整齐农田。

本项目自行设计房屋数量、朝向、距离、道路、屋顶和活动发生的时刻。房屋外形仍需结合具体房址报告进一步核对；不能仅凭“房址”二字确定完整建筑。灰坑在图上标为考古遗迹线索，未核实用途前不统一称作粮仓或垃圾坑。

资料等级只标识依据的范围，不是给文物价值打分：

- **A：具体记录**——某件藏品的名称、出土地、尺寸，或遗址中明确报告的遗迹。
- **B：同文化参照**——来自其他裴李岗文化遗址的器物，借以解释器物类型，不能当作裴李岗遗址出土物。
- **C：艺术演绎**——布局、配色、使用动作、屋顶、器物摆放和示意食物。

一件模型可以同时有 A/B 的器形依据和 C 的摆放、运动设计；不应给整座村落笼统盖上“考古还原”的标签。

## 3. 固定参考的六件核心器物

### 01–02 石磨盘、石磨棒：屋前加工

- 主参考：中国国家博物馆，1978 年河南新郑裴李岗出土 [S2]，等级 A。
- 尺寸：磨盘长 63.5、宽 28、高 7.3 厘米；磨棒长 47.8、直径 4.8 厘米。
- 造型依据：鞋底形磨盘、四短足、磨耗凹面；细长棒体。馆方介绍其配合加工谷物的用途。
- 设计：保留已有往复加工；增加放置过程、接触反馈和前后对比。谷物为情境示意，不是馆藏原物。
- 不确定边界：演示不代表真实用时、单次产量或唯一食物来源。使用动作与摆放不等同于出土位置。

**资产规则：**河南博物院另有同类磨盘、磨棒 [S8]，尺寸不同。现有模型固定使用 S2 的一组比例；不把另一件的宽度、足形等细节随意拼入后称为同一藏品。

### 03 乳钉纹红陶鼎：灶边炊煮

- 主参考：河南博物院，1977 年新郑裴李岗 M5:4 出土；高 22、口径 23 厘米 [S3]，等级 A。
- 造型依据：红陶深腹器身、三足、器腹乳钉；馆方将其解释为炊煮器，内壁留有泥条盘筑线索。
- 设计：点选后观察“三足如何给薪火留出空间”；火焰缓起，提供器身剖视，不设定具体古代食谱。
- 不确定边界：乳钉的具体功能不能讲成定论；墓葬出土背景不等于灶边原位发现。模型不可套用后世青铜鼎的造型和礼制含义。

### 04 红陶小口双耳壶：屋内器用

- 主参考：河南博物院藏、1980 年河南长葛石固出土的一件，采用文物出版社的藏品介绍 [S4]，等级 B。
- 尺寸：高 19.5、口径 5.4、底径 6.1 厘米。
- 造型依据：高领、卵形腹、小口、两侧带系孔的耳，素面。
- 设计：与陶鼎比较开口、腹部和支撑方式，引导“不同形状适合怎样的使用方式”；器物卡明确写石固出处。
- 不确定边界：没有这件壶的残留物证据，不能断言它原来装的是酒、水或某种粮食。盛贮用途作为讨论入口，具体内容物保持未知。

### 05 石铲：村边土地

- 主参考：中国国家博物馆，1978 年河南新郑裴李岗出土；长 30.3、宽 10 厘米 [S5]，等级 A。
- 已核对用途：垦荒、翻地。
- 设计：通过土层剖面和短动作解释工具与土地的关系。
- 待核对：本轮已核对馆方文字元数据，尚未完成原图轮廓核查；厚度、装柄方式不作为已确认事实。先保留裸石器展示，不凭空固定绑柄结构。

### 06 锯齿石镰：村边收获

- 主参考：中国国家博物馆，1989 年河南郏县水泉出土；长 20.6、宽 6 厘米；馆方说明属于裴李岗文化的典型器形 [S6]，等级 B。
- 造型依据：弧形薄片、细齿刃、尾部绑缚线索。
- 设计：近看锯齿，再用少量示意茎秆呈现切割；木柄外形和绳索运动属于艺术补足。
- 不确定边界：不得把水泉出土写成新郑裴李岗出土；不展示铁刃，也不声称已知其收割的确切作物。

## 4. 五个区域怎样组合

空间建议为三处住处轮廓、五个可聚焦区域；其中一处房屋可查看内部，其余用来建立邻近生活单元的关系。“三处”是控制原型规模的设计数，不是考古户数结论。

| 区域 / 稳定标识 | 核心器物及环境 | 一次主要发现 | 与其他区域的联系 |
|---|---|---|---|
| 屋前加工 `grinding` | 磨盘、磨棒、示意谷物 | 两件工具怎样配合 | 村边收获物 → 加工 → 炊煮 |
| 灶边炊煮 `cooking` | 红陶鼎、地面薪火 | 三足与受火空间的关系 | 加工食物与陶制容器在这里相遇 |
| 制陶角 `pottery` | 泥条、未完成陶坯、窑址示意 | 陶器如何逐步成形 | 为灶边、屋内的器物提供制作线索 |
| 屋内器用 `dwelling` | 双耳壶、房屋结构 | 器形差异与日常需求 | 与敞口陶鼎进行比较 |
| 村边土地 `field-edge` | 石铲、石镰、小片植被 | 翻地工具与收获工具的区别 | 通往已有磨粮互动 |

制陶角采用泥条逐层成形的教学示意，不放现代拉坯转轮。陶窑先做低矮遗迹与剖视示意；窑室完整形状、尺寸及火道结构需补充发掘图后再细化，不用圆顶面包炉外形替代证据。

灶边与加工区放在前景，制陶角偏侧后方，住处位于后方，村边土地在外围。它们之间以少量踩踏路径联系；这种位置关系是为可见性与游玩流程设计，不是遗址平面复刻。全景不画五条连线，只在区域卡中提示相关去处。

大场景的认知顺序是“看见生活 → 进入一角 → 认识物件 → 试一次操作”。用户可以自由跳转，完整参观不依赖按顺序完成五道任务。

## 5. 环境与暂缓内容

可以使用泥土地表、木构件、有限的植物、薪柴和简化搬运容器来表达生活关系；这些属于 C 类。稻、黍、粟等植物信息用于背景卡，首轮地表只画少量示意植被，不把多种作物画成同季成熟的整齐田块。

暂缓增加：人物群演、牲畜系统、纺织全流程、酿酒作坊、骨笛表演、祭祀和墓葬互动。原因是它们会扩大资料核对与动画范围，对当前“食物与器用”主线帮助有限。尤其不能把同一遗址更早地层的旧石器遗物混入这个生活时刻。
