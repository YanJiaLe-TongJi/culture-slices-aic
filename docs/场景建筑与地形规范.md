# 场景建筑与地形规范

## 渲染面与拼接规则（2026-09-29）

- 连续地块、同排屋瓦的水平尺寸不得超过布置间距，避免相邻顶面重叠。坡屋面的连续性通过厚度衔接，不靠横向放大单块覆盖缝隙。
- 砖墙灰浆底板应向内收，前、后、侧、顶面都不能与砖块外表面重合；边缘砖按墙宽裁切。夯土墙末层按剩余高度居中，不能压入上一层。
- 室内地坪、庭院铺面、地台边缘与基础地面应有明确高差，或者删除被覆盖的表面。不要用关闭深度测试、关阴影或提高渲染顺序掩盖重面。
- 验收须包含背面、斜视和旋转观察。可在开发服务运行时执行 `node scripts/check-flicker.mjs <Playwright模块路径> after`，对实际墙、屋顶、地面组件作无阴影微小转角检查；`node --import tsx scripts/browser-flicker-scenes.mjs <Playwright模块路径>` 检查24景旋转、特写及退出，并生成看图表。
- 像素阈值是回归线索，仍需查看截图；不同 GPU 的边缘光栅化可能不同，不能把单机通过等同所有硬件无闪烁。

长信宫灯造型参考：[河南博物院国宝特展](https://www.chnmus.net/sitesources/hnsbwy/page_pc/bwzl/zxgd/)的实物正面、六部分拆分照与侧面线图，并对照[中国彩灯博物馆](https://www.lantern-museum.cn/product/43259766.html)的公开图片。图片只作人工观察资料，不作为产品贴图、授权扫描模型或可复刻精度证明。曲面、纹理与衣褶由项目自行制作；卡片和AI上下文须保留该边界。

照片对照后的第二次造型校正：跪坐衣袍应有前膝与后曳衣缘，不能呈直立锥裙；领缘靠近颈部、交领顺肩胸贴合，避免用两根宽带组成大幅露胸的X形。灯盖保留袖褶的横向层次，但各层须连续过渡；铜锈与鎏金脱落采用细碎、密度有变化的色斑，不采用等大的豹纹斑点。保留原灯高、灯盘位置与交互对象标识，避免造型修改破坏镜头和操作。

1. 不看文字和器物时，三个场景的建筑体量与平面也应明显不同。
2. 地台边界服从空间：院落方整、作坊随作业分区、岸线自然、层台有高差；默认椭圆托盘不作为通用底板。
3. 屋顶必须有完整合理的坡面、脊与支承关系；不能悬空、穿插，不能为省事只保留同一段柱廊。
4. 剖切或去屋顶须为观察服务，卡片说明其展示性质；核心物件保持可见、可点击。
5. 来源与演绎边界进入物品卡和AI上下文；全景、特写、封面、窄窗口逐一检查。
6. 秦汉已按上表完成这一轮精修；后续时代也必须先做建筑依据表和实物图片观察，不能仅靠文物文字说明推想模型。
