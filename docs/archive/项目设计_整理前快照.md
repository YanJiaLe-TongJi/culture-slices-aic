## 1. 系统结构

近现代数据位于 `exhibits-modern.ts`，三处模型为 `ModernSewingScene`、`ModernCardingScene`、`ModernCinemaScene`；`ModernPrimitives` 仅共享窗框、砖块、管线和机械轮等低层构件。住宅剖面、锯齿厂房、文化场地各自组织。轮轴、脚踏、针、布、盖板、棉流、圈条、片盘、光束和银幕图形由帧循环更新，不逐帧刷新React状态。放映机特写从侧面观察片盘与镜头。

明清内容在 `exhibits-ming-qing.ts`，模型分别为 `MingStudyScene`、`QingPorcelainScene`、`QingNewyearScene`。椅圈和器形使用连续曲面，院落地面、藤编和砖墙实例化；椅子、木件、卷轴、笔刷、釉层、纸面与色层由渲染帧更新。年画纸面绕横轴翻转，版面图案相应纵向镜像；印纸有承托台，完成后移至画门子。施釉动画聚焦瓶身，静态选择仍可查看釉浆盆。

宋元内容独立置于 `exhibits-song.ts`，模型由 `SongTeaScene`、`SongBridgeScene`、`YuanLandscapeScene` 实现。茶末、注水、泡沫、击拂、倒桅、过桥、山岸纵深与墨层均由渲染层推进。静态山体与皴点用实例化；移动对象完成后按落点调整镜头与标签，刷新恢复继续使用原存储契约。三处共15对象、九动作，状态不依赖AI接口。

React/TypeScript 网页 → Node/TypeScript 同源 API → 可配置的文本模型。

网页内部：界面状态 → 确定性的交互状态 → 三维显示；事实内容从共享内容模块载入。模型只生成讲解，不修改状态或判定操作结果。

- React 19、Vite 7；锁文件固定实际安装版本。
- Three.js、React Three Fiber 与 Drei 提供相机和三维基础。
- 原生 Node HTTP 服务处理 API；开发模式复用 Vite 中间件，生产模式提供 dist。
- 无数据库、内容后台、向量库或通用场景编辑器。
- 配置使用 `.env`，接口默认只监听 127.0.0.1。

## 3. 三维与交互

体素位置、尺度和色彩由确定性的生成函数创建，合并为少量 InstancedMesh。磨盘保留简化的四足与凹面线索；磨棒由连续体素形成。不要将艺术造型当作原物测量。

相机采用正交斜俯视，旋转与缩放有边界，禁用平移；选中对象使用插值移动目标，相机缩放随窗口限制调整。名称提示通过相机投影定位，DOM 由 React 管理，同一时刻最多一个。没有常驻标签、描边后处理或持续闪烁。

`view` 记录对象，去重保存；`place` 幂等；`grind` 必须先 place，进度限制在 0–1；达到 1 才加入 ground。`replay` 清除本轮加工完成标记，保留观察和放置；`reset` 清空全部探索记录。

拖动区域通过 pointer capture 接收移动，累计有效水平距离。演示定时增加同一状态机的进度。交互期间 OrbitControls 禁用；退出时解除锁定。左右方向键可替代拖动。

高亮通过每个 Target 组内材质的暖色自发光叠加实现，并保留原始发光值：默认轻微提亮、悬停增强、选中保留。全景将物件映射到其区域；局部保留物件标识。透明点击盒扩大细小器物范围，不遮蔽渲染。标签延迟 150 ms，pointer-events 为 none；旋转、切区、加工和放料清除提示。键盘聚焦 DOM 入口也提供目标状态。

放料使用可变动画时钟；requestAnimationFrame 推进时间，useFrame 更新容器与粒子变换、谷粒实例数量，进度条直接更新 DOM。开始、取消、完成才触发 React 状态变更。下落谷粒共享 InstancedMesh；稳定状态仅在完成后提交。取消或卸载不会产生延迟完成，降级模式仍可通过同一时钟完成操作；减少动态效果时直接完成。

## 4. 数据与持久化

- EraDefinition：id、标题、排序、简介、引导问题、三个场景位置。
- SceneSummary：id、所属时期、标题、主题类别、简介、ready/planned 状态；仅 ready 提供封面。
- SceneDefinition：主题、文化背景、对象、步骤、资料引用。
- ObjectDefinition：id、名称、类型、介绍、事实、细节、来源、场景位置。
- SourceEntry：id、机构、标题、URL、核对摘要。
- Progress：version、entered、viewed、actions、grinding。

localStorage 使用 `culture-slice:progress:v1`。解析错误或不兼容版本回到初始状态；字段过滤并修复不一致记录。存储不可用时提示用户，本次体验继续。

聊天内容只存在当前场景内存；刷新、重置、离开场景后清除。重置与卸载都会取消客户端问答请求；卸载关闭 AudioContext、停止演示定时器、取消放料 RAF，并卸载 Canvas。

新增场景使用 `culture-slice:exhibit:<sceneId>:v1`，保存 entered、viewed 与有序 actions。恢复时仅接受有效物件和最长连续动作前缀；不能用另一个场景的动作跳步。`culture-slice:last-scene:v1` 只记录最后进入的可探索场景，缺失时继续兼容原村落记录。临时动画、问题文本、音频及样式参数不写入稳定进度。

`ActionClock` 通过 RAF 更新连续时间，模型 useFrame 读取。完成后才追加对应动作。取消、切场景或卸载不会触发过期完成；重放保留观察记录并清空动作，重置清空当前切片。合成声仅在用户试听操作后创建 AudioContext，离场关闭。

### 路由与资源

`/#/era/<id>` 浏览时期；`/#/scene/<id>` 进入已登记且 ready 的切片（原村落仍为 peiligang-grain）；空哈希默认史前。未知时期、未开放场景或错误格式进入明确的未开放页。监听 hashchange 处理前进后退；分享只包含当前入口，进度仍留在本地。

根 App 仅静态引入时间轴。Experience 通过 React.lazy 动态导入，构建将 Three/R3F 与场景放进独立块；原村落与新增体验分别懒加载，底层 Three/R3F 控制器块由构建复用。首页无 Canvas，也不预加载三维块。离开场景后组件卸载；再次进入可复用浏览器模块缓存，但重新创建唯一 Canvas，并恢复相同存储键的记录。封面为自行制作场景的截图，生产服务提供 image/png。

继续沿用当前 Web 技术栈，不将未来切片数量等同于同时运行的场景数量。性能判定使用实际 renderer，分别记录硬件与 SwiftShader；没有因本轮增加 WebGPU 或客户端引擎。

## 5. API 契约

### GET /api/status

返回 `{ configured: boolean }`，仅用于说明自由问答是否配置，不返回服务地址、模型凭据或其他环境变量。配置存在不代表供应商一定可达。

### POST /api/chat

输入示例：

```json
{"sceneId":"peiligang-grain","objectId":"slab","actions":["placed"],"question":"为什么石面有凹陷？","history":[]}
```

`objectId` 可为 null；允许动作仅 placed、ground；新增切片的对象标识与动作序列按其自身定义验证，zoneId 必须为空；不接受跨场景物件、动作或跳步。问题 1–1000 字符；历史最多 8 条，只接受 user/assistant 角色，每条最多 3000 字符。HTTP 请求体限制 20 KB。

响应：

```json
{"answer":"回答文本","sourceIds":["nmc-grinding-tools"],"mode":"live"}
```

未配置返回 mode=preset，不进行网络调用。错误采用 `{error:string}` 与 400/403/413/502/503/504 等状态，前端展示可读消息和重试。

## 6. 模型上下文与可信边界

服务端从已登记内容加载事实，不接受客户端提供的“来源正文”。上下文包括文化线索、当前物品、已完成动作、人工核对摘要和最近对话。

要求模型区分事实与艺术演绎，对资料不足明确说明，不扮演真实历史人物。输出使用 `{answer,sourceIds}`，服务端验证格式、长度和登记来源标识；未知标识被丢弃；新切片只允许当前场景登记的来源，不能混入磨粮或其他场景的引用。标识正确不能证明回答正确，仍需人工按案例核查。

供应商适配使用完整的 chat-completions HTTPS 端点；本地 loopback HTTP 可用。20 秒超时，网络或模型输出异常返回可重试错误，绝不将供应商原始错误和密钥发给浏览器。

## 7. 故障与扩展

- 无模型：静态体验与预置讲解继续运行。
- 网络异常：保留已输入问题，支持重试；场景状态不受影响。
- 三维不可用：显示解释，保留 DOM 物品入口与资料。
- 浏览器存储不可用：只影响跨刷新恢复。
- 下一切片优先增加内容和独立模型组件；出现真实复用需求后再提取公共能力。

首版按单用户本地原型实现。面向公网发布前另行评估鉴权、调用配额、服务部署和模型成本；不把当前本地 API 直接暴露为公共无限调用端点。

支持该能力的浏览器可注册只读 `read_culture_scene` 工具，返回相同的场景选择和进度状态，不执行操作或调用模型；不支持时自动跳过。该可选接口不属于首版用户体验验收的前置条件。
