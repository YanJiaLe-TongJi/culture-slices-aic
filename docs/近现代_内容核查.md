# 近现代三切片：参考与内容核查

2026-09-28。生活、生产和文化分别采用工人新村缝纫角、梳棉工场、公共场地放映；不将八个大时期画成单一技术优劣排序。原型模型和纹样自行制作，参考照片不作为产品资产。

## 内容边界

- [商务部老字号资料](https://lzhbwg.mofcom.gov.cn/edi_ecms_web_front/thb/detail/047b77d8642942f3b66c3d6b81d528d7)支撑缝纫机与20世纪70年代家庭记忆的关系；不把商号起源当作蝴蝶品牌启用年代，不断言人人拥有。
- [长白一村说明](https://www.shyp.gov.cn/shypq/xwzx-bmdt/20230721/432947.html)支撑两层、一室户和共用厨卫；模型是局部剖面，不是某栋完整住户平面。楼板留出梯口，二层前部和前墙为展示切口。
- 国博梳棉机为1895年英国制造，转拨大生使用；张之洞订购、张謇办厂与制造者不能混淆。输出棉条仍要后续加工，不直接当成成纱或织物。
- [南通北车间资料](https://wglj.nantong.gov.cn/ntswgxj/bmdt/content/229310eb-5f37-4e9a-b50f-bdc969076455.htm)记录砖木锯齿厂房与1985年原构件迁建因素。网页直接读取受限制，使用已检索的官方正文信息，不声称已查看该网页厂房照片。机器与厂房关系重组，未复刻1895年生产线。
- F16-10以2009年产品页为参考，不冒称1952首台国产16毫米机。页面标注24格每秒与光学还音；网页用平滑动画解释，不模拟闪烁和实际穿片操作。
- 淮安原文化宫2007年拆建，不能宣称2009年页面机器实际在那里放映。建筑类型与流动放映是明确标注的教学组合；不复制电影片段或真实电影海报。
- [2010年数字放映转换文件](https://www.chinafilm.gov.cn/xxgk/zcfg/gfxwj/ncdyfygc/201001/t20100121_1516.html)只作为历史转型资料，不当作当前政策建议或今天设备普及率的证明。
