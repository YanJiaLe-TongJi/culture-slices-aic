# 宋元三切片：内容与图像核查

2026-09-28。当前主题是点茶、虹桥船运、元代山水画境。博物馆资料用于事实与器形，建筑、动画和地形均明确艺术推定。程序通过引用校验，不等于真实模型回答或专业鉴定已经验收。

## 已查看的参考图

- [国博建窑黑釉兔毫纹盏](https://www.chnmuseum.cn/zp/zpml/csp/202203/t20220309_254231.shtml)：敞口收腹、短足、深色釉、细密纵向结晶、足部露胎。实物图保存于 `artifacts/reference-song-bowl.jpg`，仅用于观察。
- [国博白釉贴塑铺首衔环纹执壶](https://www.chnmuseum.cn/zp/zpml/kgfjp/202112/t20211203_252543.shtml)：小腹、细长颈、带盖口、细长上扬流、曲柄、肩部铺首衔环。已查看 `artifacts/reference-song-long-spout.jpg`；不能误用早前检索到的唐代短流茶瓶。
- [故宫张择端《清明上河图》](https://www.dpm.org.cn/collection/paint/228226.html)：已查看馆方虹桥局部 `artifacts/reference-qingming-full.jpg`。木拱有交错支承，桥面无廊屋；船舱、桅杆、岸边瓦屋、临街敞棚用于空间关系参考。场景省略人群，并非原画逐件复原。
- [台北故宫无用师卷](https://digitalarchive.npm.gov.tw/Collection/Detail/1194?dep=P)：通过馆方公开IIIF清单查看卷中局部 `artifacts/reference-fuchun-detail.jpg`，可辨圆缓山峦、坡岸、树丛和水面。研究文《画中寓亭》中的子明卷图片不作为无用师卷的图像依据；馆方全卷缩略图及装裱、卷背图也不能代替画面细节。

第三方图像没有进入产品 `public`。茶盏釉纹、山体墨线、模型与封面均自行制作，封面来自实际运行截图。模型不是扫描、考古测绘或施工图。

## 事实与演绎的边界

点茶方法参考[国博妇女涤器雕砖说明](https://www.chnmuseum.cn/zp/zpml/csp/202008/t20200825_247299.shtml)：茶末入盏，少量沸水调匀，渐注水并环回击拂。投末、壶流和茶筅接触茶汤采用连续动作，调膏与注水压缩展示。泡沫不作为茶艺评分；黑釉盏与白釉壶不是同套出土器。

虹桥结构另参考[故宫贯木拱虹桥研究](https://www.dpm.org.cn/study_detail/100191.html)。桥面移开只用于教学剖视，不能误说成历史上的开合桥。倒桅有原画说明，动画转轴、固定桅根、船体与净空为简化；没有承重、水动力或操船仿真，不提供工程结论。

富春画境参照无用师卷与[馆刊画中寓亭研究](https://www.npm.gov.tw/NewChineseArtDownload.ashx?bid=2345)。模型展开的是重新组织的纵深，墨层与小舟帮助解释疏密和留白。茅屋、亭、岸、林与山峰不对应实地坐标，也不能概括为所有元代民居。

## 人工问答核查案例

| 提问或上下文 | 参考回答边界 | 来源 |
|---|---|---|
| 兔毫纹是画上去的吗？ | 烧成结晶；程序纹理只是外观示意 | 国博兔毫盏 |
| 选中黑盏后问“这个为什么是黑色的？” | 说明黑釉、与茶沫对比；不编造具体配方 | 国博兔毫盏 |
| 壶嘴为什么这么长？ | 控制注水，联系点茶；不声称精确流量 | 国博长流壶 |
| 刚才击拂之后发生了什么？ | 根据完成记录解释泡沫；不能替用户声称熟练掌握 | 操作记录、国博点茶 |
| 唐代人都这样用茶筅吗？ | 不把宋代点茶回填为全部唐代饮茶 | 国博点茶、唐切片说明 |
| 虹桥是石桥吗？ | 北宋原卷为木桥，不能混淆后世版本 | 故宫原卷 |
| 桥面打开后船才过去，古人也这样吗？ | 打开是教学剖视，没有史料支持开合说 | 结构研究、演绎说明 |
| 选中船桅后问“为什么要放下来？” | 联系桥孔净空及原画，尺寸为推定 | 故宫原卷 |
| 刚才那艘船用什么动力？ | 原画有人操船，动画省略人；不编造自动动力 | 故宫原卷、演绎说明 |
| 这座桥能承受几吨？ | 当前资料与模型不足，无工程计算 | 资料不足 |
| 富春山居是哪位作者、哪个时代？ | 元代黄公望，无用师卷题识1350 | 台北故宫 |
| 这几座山今天能按地图找到吗？ | 不把画意或3D组合当实测地形 | 台北故宫 |
| 选中江面后问“这里怎么没画？” | 解释留白与山树疏密关系 | 台北故宫 |
| 小舟里是黄公望本人吗？ | 没有此识别依据；模型人物为意象 | 资料不足 |
| 这套茅屋证明元代房屋都很小吗？ | 图像线索不是通用建筑结论 | 台北故宫、画中寓亭 |

实际模型自由问答、专业考古复核与五名目标用户盲测尚未完成。本批核验预置说明、操作上下文、来源标识和失效反馈；后续接入凭据后逐题人工评价事实准确性。
