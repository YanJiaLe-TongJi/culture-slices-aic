# 新石器村落：场景与动画设计 v0.2

历史设计记录：下文保留v0.2目标与当轮落地情况，其中五区域、八对象等数量仅对应当时版本。当前v0.10.1为六区域、十个观察入口，范围与验收见[需求说明](需求说明.md)及[验证状态](验证状态.md)。

日期：2026-09-28。状态：v0.2 核心浏览与互动已实现。本轮依据见《新石器村落_文物依据与组合》。以下保留设计目标，实际落地差异列在文末。

## 1. 这一轮要验证什么

用户能否先读懂一个小村落，再顺畅进入其中一个精致的生活角落？操作中的物体变化能否连续、可理解？

保留体素微缩风格与鼠标操作，采用“村落全景 → 生活区域 → 器物特写”三层浏览。现有磨粮互动成为 `grinding` 区域，保留 `slab`、`roller`、`grain` 对象标识及其已完成记录。

## 2. 构图草案

下图仅表示游戏空间的邻接关系，不是遗址平面图，也不对应真实方位。

```text
                  后景：地形、少量植被
          [住处轮廓]  [可剖视住处]  [住处轮廓]
                         屋内器用
             制陶角       小空地       村边土地
                       屋前磨粮
                         灶边炊煮
                     前景：主要观察入口
```

- 全景能同时看见主要区域；建筑不遮住前景器物与入口。
- 只给当前悬停区域显示名称，其他入口用克制的视觉提示，避免五个常驻大标签占据场景。
- 三处房屋形成聚居感，但只精修一处内部。新增面积用于建立活动之间的关系，不用密集装饰填空。
- 粗模先验证投影、遮挡和相机距离，再决定地台最终尺寸，不直接沿用单个地台乘固定倍数。

## 3. 三层镜头与区域操作

| 层级 | 画面重点 | 点击结果 | 返回行为 |
|---|---|---|---|
| 村落全景 | 空间关系与区域轮廓 | 选择区域，约 0.8–1.2 秒靠近 | 恢复初始全景 |
| 区域 | 2–3 件相关物品 | 点物件，约 0.4–0.7 秒进入特写 | 回到进入前的全景视角 |
| 物件 | 器形、动作与资料 | 查看、执行区域动作 | 回到该区域，不直接跳到全景 |

上述时长是待试玩调节的设计值。镜头位置、观察目标和缩放同时缓动；切换区域不重新加载世界。面板开启时调整画面构图，为物品保留空间。提供“返回区域”和“村落全景”清晰的层级出口。

屋内区域聚焦后，屋顶分段抬升或淡出；动画结束再开放内部对象选择。离开后复原。透明对象的排序与遮挡需实测；若出现问题，使用几何移开而非多层半透明。

加工过程中锁定相机。切区前结束当前临时动作，不能让拖磨手势同时旋转镜头。连续点击新区域时从当前相机姿态转向最新目标，不排队播放过时的移动。

## 4. 谷物放置：从突现改为连续动作

建议用一个明确标为场景示意的浅容器承载原料，避免尚无依据时冒称某件馆藏盛粮器。动作约 1.6 秒，先按以下节奏制作再试玩调整：

| 时间 | 画面 | 状态 |
|---|---|---|
| 0–0.2 秒 | 容器轻抬，工具让出放料位置 | `lifting` |
| 0.2–0.6 秒 | 沿短弧线移到磨盘上方 | `carrying` |
| 0.6–1.2 秒 | 容器倾斜，少量谷粒流出；原料逐渐减少，盘上堆积逐渐增加 | `pouring` |
| 1.2–1.6 秒 | 谷粒落定，容器返回，磨棒就位 | `settling` |
| 完成 | 开放“开始加工” | `ready` |

使用预设轨迹和实例化粒子，不做复杂刚体模拟。落料点要与盘上堆积吻合；盘上谷物不是最后一帧整体切换可见性。容器搬运不代表已知的史前动作方式。

状态要求：

- `place` 只在放置完成时提交，动画中按钮禁用，重复点击不生成多份粒子或多个完成回调。
- 临时动画状态独立于已完成动作；刷新不保存半空中的容器。尚未提交时恢复未放置，已提交时恢复已放置。
- 中途离区或关闭动作卡：取消动画、回到放料前状态。重置同时取消动画回调，防止稍后把谷物重新放回。
- 页面失焦暂停，恢复后继续，不累计一大段时间造成突然结束；提供“跳过动画”，直接提交稳定完成状态。
- `prefers-reduced-motion` 使用短淡入和简短文字反馈，省略大幅移动，完成判定与正常模式一致。

加工也要连续：磨棒先落到接触高度，再往复运动；加工后的谷物示意渐变出现，声音随有效动作渐入渐出。离开接触面时不继续累加加工进度。

## 5. 模型打磨标准

| 对象 | 本轮要改的具体内容 | 检查方式 |
|---|---|---|
| 磨盘 | 连续表面、略有不规则的外轮廓、可见的四足、温和凹面与磨耗区 | 全景识别轮廓；特写看得到“有足、有承托面” |
| 磨棒 | 按指定藏品的长度比例细化，端部不做成粗大方锤 | 与磨盘组合检查接触关系 |
| 谷物 | 少量可辨颗粒与堆积体结合，落料时有来源和去向 | 慢速播放检查突现与穿模 |
| 陶器 | 鼎足与壶耳优先保留，粗陶表面少量色差，器口具有厚度 | 特写可区分鼎和壶，不靠标签识别 |
| 房屋 | 木构与泥墙的层次，屋内可读的空间；不确定的屋顶保持简化 | 聚焦时不遮挡对象，卡片说明演绎部分 |
| 地面 | 连续土层、小范围踩踏痕迹与高差，减少均匀棋盘格 | 全景看得出活动区，环境不抢主体 |

继续使用实例化体素，但按对象尺度划分精度：地形较粗，器物较细，器口和镰齿允许少量补充几何。体素风格通过配色、轮廓节奏和材质统一，不要求所有物体使用同样大的立方体。

固定种子的色彩变化应沿表面形成块面；避免每块随机换色导致噪点。石、陶、木、土分别设置色差范围和粗糙度。细节层级切换不改变可交互对象的标识与碰撞区域。

## 6. 对现有工程的最小扩展

- `content.ts` 增加区域定义 `ZoneDefinition`，包含对象 ID、引导问题、相机目标和来源。给对象补充出土地、参考标本、事实/演绎说明，避免只挂一个全场通用链接。
- 将 `Scene.tsx` 中的磨粮组提取成独立区域组件；村落外壳和其他区域按组件组织。先拆当前真实需要复用的几何工具，不搭建通用编辑器。
- 镜头状态区分 `{ level: 'village' | 'zone' | 'object', zoneId, objectId }`；返回时保留前一层镜头。
- 将放置动画的临时状态与 `state.ts` 的稳定探索进度分离；加工逻辑仍由程序判定。
- 后端同步登记新区域和对象，校验其所属关系。AI 上下文增加当前区域、当前对象及对象自己的来源；不能只改前端后仍让模型拿单一磨盘资料回答所有区域。
- 新增动作需要同时修改前端状态、服务端校验及上下文。未实现区域先只开放观察与解释，不伪造“已制陶/已收获”的记录。
- 本地进度如升级版本，显式迁移旧 `slab/roller/grain` 记录；只读取旧版中有效的观察和完成动作，不能因新村落上线无声丢失旧进度。

## 7. 可运行的推进顺序

1. **磨粮精修版**：先完成连续放料、磨盘/磨棒比例和材质、动作取消/重置，现有闭环保持可玩。
2. **村落浏览版**：加入村落外壳和五处区域入口，完成全景—区域—物件镜头；其他区域至少能查看模型、卡片和依据。
3. **生活联系版**：先做陶鼎受火空间和泥条成形两项轻交互，再补石铲/石镰示意；根据试玩结果决定是否继续扩展。

每一步都交付可运行版本。镜头、连续动画和模型可读性先于场景装饰、人物数量和更多文物。

## 8. 验收补充

- 放料时连续点击、切区、重置、刷新、页面失焦和减少动态效果设置均不会产生幽灵完成事件。
- 三层浏览与返回路径明确；磨粮期间不误旋转；打开侧栏不挡住操作对象。
- 全景可辨认生活区域，近景器形可辨认；房屋遮挡和标签位置在常用与窄窗口检查。
- 每张新器物卡对应正确的标本、出土地与来源；同文化参照和艺术补足可区分。
- 所有旧版核心浏览器流程仍通过，增加新镜头与动画的必要测试。
- 在同一测试设备重新测量资源与帧率，不沿用旧版单地台的性能结论。

## 9. v0.2 实际落地 · 2026-09-28

- 三处住处轮廓、五个区域、八个可选对象已接入。六件器物线索之外，谷物与泥条陶坯标为示意对象。
- 三层镜头与面包屑可用；保存已停稳层级的镜头，未停稳的快速跳转直接转向最新目标。
- 放料实际采用约 2.2 秒，以一个时间参数同步容器、源谷物、粒子和盘上谷物。取消/离区/重置不提交放置；刷新恢复稳定状态。隐藏页面暂停，跳过及减少动态设置可直接完成。
- 灶边可点火/熄火，制陶角可反复观看约 4 秒泥条成形；屋内屋顶抬升缩去、前墙降低。村边目前提供工具观察与资料，没有模拟翻地或收割动作。
- 精修磨盘、磨棒、陶鼎、双耳壶与村落地台。地台内部不生成不可见立方体面，表面使用合并几何；阴影缓存并在动作期间限制更新频率；低帧率时自动降低三维分辨率，保留 DOM 文字清晰度。
- 进度结构保持 v1，扩展允许恢复的对象标识，因此旧磨粮进度可直接读取。新区域点火/泥条展示不记为学习完成。
- 区域与器物及来源由服务端校验；离线推荐问题匹配新器物，在线回答只接受本次上下文中登记的来源。
- 仍没有通用场景编辑器；模型集中在 Scene.tsx 内的区域与器物组件，动画时间逻辑独立在 placement.ts。
